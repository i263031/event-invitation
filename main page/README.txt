STEPHANIE & WILLIAM — WEDDING WEBSITE (MAIN PAGE)

FILES
- index.html : page structure and content
- style.css  : responsive styling, colors, typography and layout
- script.js  : mobile navigation and image carousel behavior

HOW TO RUN
1. Keep all three files in the same folder.
2. Open index.html in a browser (Chrome, Edge, Firefox, etc.).
3. An internet connection is required for Google Fonts and the Unsplash carousel/hero photos.

THEME PALETTE
- Ink:       #211B1B
- Burgundy:  #6F1735
- Taupe:     #AA9E91
- Blush:     #E5C7BD
- Stone:     #D9D6CC
- Paper:     #F7F2EE

FONTS
- Great Vibes: names and handwritten accents
- Cormorant Garamond: elegant headings and invitation text
- DM Sans: navigation, labels and supporting text

SUGGESTED THREE-PAGE WEBSITE STRUCTURE
1. Home (this page): introduction, invitation preview, image carousel and key event details.
2. Our Story: how the couple met, their journey, and a few meaningful photos.
3. Event & RSVP: venue map, schedule, dress code, guest response form and contact information.

NOTES
- The event name, date, venue and schedule are sample details adapted from the supplied previous lab invitation. Update them if your instructor expects different details.
- The carousel uses remote Unsplash images. Replace the image URLs with your own approved photos if required.
- The email link is a placeholder and should be updated to a real contact address if you use it.
